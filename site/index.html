The packages install mpv for you. Release notes

FedoraFedora 40+
tuner-iptv-….x86_64.rpm Download .rpm
Arch Linuxx86_64 · ARM64
tuner-iptv-bin · tuner-iptv-git View PKGBUILD
Any LinuxTerminal only · bring your own mpv
tuner-tui-v…-linux-musl.tar.gz Download
Debsudo apt install ./tuner-iptv_*_amd64.deb
Rpmsudo dnf install ./tuner-iptv-*.x86_64.rpm
Archcd packaging/aur/tuner-iptv-bin && makepkg -si
Cargocargo install --locked --path crates/tuner

Then run tuner playlist.m3u or tuner-gtk. Accounts live in ~/.config/tuner/config.toml.
